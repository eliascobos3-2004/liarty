# 🚀 Liarty - Tu Asistente Personal Inteligente

Desarrollado con dedicación por **EL-33**.

**Liarty** es una aplicación de productividad integral diseñada en Flutter que combina la potencia de un asistente virtual con herramientas de organización personal, seguimiento de metas y datos contextuales como el clima y las fases lunares.

---

## ✨ Características Principales

*   **🤖 Asistente Liarty:** Un chat interactivo que te guía para agendar tareas, rutinas y listados de forma natural.
*   **📅 Agenda Dinámica:** Gestión de tareas con prioridades, recordatorios visuales y un sistema de cumplimiento.
*   **🔄 Rutinas Laborales:** Visualización completa de tus actividades de lunes a viernes.
*   **🌤️ Info Contextual:** Clima en tiempo real (vía OpenWeather) y cálculo astronómico de fases lunares.
*   **🎯 Sistema de Puntos:** Gamificación de tu productividad; gana puntos al completar tus objetivos.
*   **🎨 Personalización:** Elige entre temas de colores sólidos o imágenes de fondo atmosféricas.
*   **🔒 Privacidad:** Diario personal con encriptación ligera para tus notas más importantes.

---

## 🛠️ Tecnologías Utilizadas

*   **Flutter & Dart** - Framework de desarrollo.
*   **Hive** - Base de datos local ultrarrápida (NoSQL).
*   **Geolocator & OpenWeather API** - Servicios de ubicación y clima.
*   **Flutter Local Notifications** - Sistema de alarmas y recordatorios.
*   **GitHub Actions** - Automatización de compilación de APK.
